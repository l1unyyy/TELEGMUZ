TELEGMUZZ MINI APP — БАЗОВАЯ ВЕРСИЯ

1. Загрузите index.html, style.css и script.js в папку miniapp вашего репозитория.
2. Опубликуйте папку как статический сайт (например, GitHub Pages).
3. В BotFather укажите HTTPS-адрес сайта как URL Mini App.
4. Откройте Mini App в Telegram.

Что уже работает:
- адаптивный интерфейс для телефона;
- Telegram WebApp SDK подключён;
- поиск по демонстрационным трекам;
- добавление/удаление избранного (сохраняется локально);
- выбор трека в нижнем мини-плеере;
- переходы между поиском и избранным.

ВАЖНО:
Это пока фронтенд-заготовка. Настоящий поиск через yt-dlp/SoundCloud и аудио
из Telegram-бота ещё не подключены. Нельзя безопасно отдавать Mini App токен
бота или напрямую запускать yt-dlp в браузере.

Подключение API:
- откройте script.js;
- задайте API_BASE_URL, например https://ваш-домен;
- сервер должен отвечать на GET /api/search?q=запрос JSON-объектом:
  {"tracks":[{"id":"1","title":"Название","artist":"Исполнитель",
  "cover":"https://...","duration":"3:21","audio_url":"https://..."}]}

audio_url должен быть доступен браузеру по HTTPS и разрешать CORS.
Для Telegram file_id нельзя просто подставить его вместо audio_url:
боту понадобится отдельный серверный endpoint/механизм выдачи аудио.
